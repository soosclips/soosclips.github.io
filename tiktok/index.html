Soos Clips – TikTok connection

Soos Clips is a single-operator tool that publishes the owner's own short gaming highlight videos to the owner's own TikTok account (@soos.clips). Sign in with TikTok to connect the account; the tool then uploads finished MP4 clips with the Content Posting API (Direct Post) using the caption and privacy level the owner chooses.

Log in with TikTok

Requested permissions: user.info.basic (display name and avatar, to confirm the connected account), video.upload and video.publish (to post the owner's videos).
